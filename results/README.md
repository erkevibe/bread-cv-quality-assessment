# Generated results and licensing

Aggregate metrics, statistical summaries, figures, and the final-test prediction table are
generated by `make experiment`. Source images, the source measurement CSV, the full manifest,
extracted features, inventory, validation predictions, and trained weights are excluded from Git.

The software is MIT-licensed. `results/predictions/test_predictions.csv` is a derived result from
Juan Mora's Mendeley Data version 1, DOI `10.17632/f663p7c89m.1`, and is distributed with the
dataset's CC BY 4.0 attribution. It must not be represented as an independently collected dataset.
